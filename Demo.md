# Demostración para Instructores - Agentes seguros en Copilot Chat mediante Agent Builder

El propósito de este documento es sugerir la demostación que el instructor puede realizar durante la entrega del seminario Introducción a Agentes seguros en Copilot Chat mediante Agent Builder. Los siguientes pasos son generales, se entiende que el instructor tiene las habilidades para comprenderlo. Están organizados en orden de los slides de Power Point adjuntos. 

## ¿Qué son los agentes de Microsoft 365 Copilot?

* Acceder a M365 desde el navegador para revisar la plataforma y ver el licenciamiento básico. Si es posible, comparar los agentes disponibles por tipo de licencia.

## Chat de Microsoft 365 Copilot vs Agentes especializados

* Realizar prompting con MS365 Copilot chat y compararlo con uno de los agentes predefinidos.

## Uso del agente Idea Coach

* Usar el agente Idea Coach, temas sugeridos por los estudiantes.

## Uso del agente Microsoft 365 Admin

* Usar el agente Microsoft 365 Admin con los prompts de sugerencias. (Se requiere permisos de administrador)

## Uso del agente Learning

* Usar el agente Learning, temas sugeridos por los estudiantes.

## Creación de agentes mediante lenguaje natural

* Crea un agente de un tema sugerido por algún estudiante en lenguaje natural 

## Creación de agentes personalizados

* Crea un agente de un tema sugerido por otro estudiante de manera personalizada

## Componentes principales de un agente

* Ingresar también a Microsoft 365 Copilot premium, crear un agente y mostrar las diferencias en cuanto a: conocimientos, acciones, etc.
